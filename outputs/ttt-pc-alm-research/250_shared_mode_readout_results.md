# 250｜新增解释确实有查询价值：共同读出与完整冷启动成本

本轮把“多找到一个分支”推进到了实际查询效果。对247中乘子切换独有的分支，严格验证了正体积；固定已有解释和读出，只把该分支加入后，五次固定重复的查询误差全部下降。它不是重复的坐标停滞示例，也不是只比较信用库容量。

同时，所有优化器采用同一个模式体积读出后，原有的短预算ALM16对照在这16个旧任务上显示了值得继续检验的质量—成本组合。**主候选仍是停滞切换128，不能把事后表现更好的ALM16改名成预先成功的主方法。** 这两层证据都保留，核心研究尚未完成。

## 1．统一了什么，没有额外给候选什么

按[249执行前协议](249_shared_mode_readout_protocol.md)，输入仅为247冻结的16旧任务×10优化器全部真实参数分支。每个方法对自己的可行分支使用相同polytope求解器、相同严格内部点验收、相同体积权重、同2048粒子总预算和同257查询点。

10个实际方法各重复5次，另外两个明确标为容量诊断的池是“其它9法并集”和“再加入候选的10法并集”，合计960个预测。所有预测、粒子、几何和高预算边际诊断先保存，再统一评估查询答案。未重启发现器、未改步数/起点/触发条件，也没有给候选独享LP修复。

所有116个可行区域都获得正体积数值几何；随后对每个区域构造有理超立方体，直接验证16个角点的真实前向路径、偏置盒和支持噪声约束。1856个精确角点全部通过，证明这些区域不是仅有边界的伪模式。体积值本身仍是浮点几何计算，不冒充有理精确体积。

没有正体积池的情况保留原方法点预测，不能用他法解救场；60份空池重复预测全部重放通过。使用统一读出不等于每个方法已找到完整后验，其未发现质量仍未知。

## 2．一个晚发现、但有实际价值的新模式

唯一相对其它9个优化器全轨迹并集仍独有的分支位于5900007，编码

`01010202010101010202020202020102`。

来源追踪确认它由第4个重启产生：第106轮后触发乘子切换，第128轮第一次进入该真实参数分支，仅在这个重启和这一步出现。它不是246暖启动示例的第8个重启，不能混写为同一条轨迹。

该分支的数值体积约1.37942556e−10，占当前7个已发现模式并集体积的36.812999%。这个占比只针对已发现并集，**不是完整真实后验质量占比**。绝对体积小并不意味着它在当前条件后验中无关。

为隔离新增模式本身，每个模式固定8192粒子、5次重复；同一重复下旧6个模式的预测完全复用，只加入新模式并按体积重新加权。结果：

| 量 | 结果 |
|---|---:|
| 旧6模式平均查询MSE | .080312830 |
| 加入新模式后平均查询MSE | .073424225 |
| 平均变化 | −.006888605 |
| 5次变化范围 | [−.007306076, −.006623371] |
| 下降重复数 | 5/5 |

这是该旧任务上的有限预算新增解释收益，不是五个新任务的独立确认，也不是“其它优化器永远无法找到该模式”。更强初始化、重启或搜索仍可能覆盖它，后续不能禁止这些对照。

证据：[真实来源轨迹](../../results/shared_mode_readout/analysis/novel_mode_provenance.json)、[逐重复风险分解](../../results/shared_mode_readout/development/marginal_evaluation.json)。

## 3．收益的数学表达不是“模式更多一定更好”

在均匀先验和均匀噪声下，对已发现集合D的条件后验均值记为m_D；新增不重叠正体积区域E后，

\[
m_{D\cup E}=(1-w)m_D+w m_E,\qquad
w=\frac{|E|}{|D|+|E|}.
\]

对当前教师t与相同查询测度，风险差恒等于

\[
R(m_{D\cup E})-R(m_D)
=2w\langle m_D-t,m_E-m_D\rangle
+w^2\|m_E-m_D\|^2.
\]

后项非负，所以仅“新区域可行”不能保证泛化收益。这里五次重复中第一项均足够负，抵消新增变化的平方代价；独立重算五次恒等式全部通过。新增解释与旧预测的误差具有正确方向的互补，才是实际下降的原因。

这给出一条比“乘子能动起来”更完整的机制链：残差信用抵消导致局部停滞 → 累积乘子跨分支 → 获得先前漏掉的可行解释 → 在相同概率读出下改变未见查询预测。最后一步仍有任务条件，不是从前面自动推出。

## 5．实测开销主要在哪里

ALM16真冷启动.211482秒分解为：模式收集和局部发现.023011，几何和验收.157414，采样加查询读取.031057。几何约占74.4%。Adam60相应为.039834/.159086/.028214；GN20为.073080/.096548/.027878。这里BP的所有实际试探点也收集分支，不能只收ALM的每轮轨迹却漏掉BP线搜索点。

完整资源实验有160次正式冷启动和20次单独跟踪内存运行，另有10个完整流程热身；180次正式结果中的粒子、分配和预测与冻结249结果逐位相同。所有部署路径不读原实验的候选或几何，原文件仅在计时完成后用于比对。

两任务上的Python跟踪峰约16.96—17.15MB，主要包括2048粒子查询读取的临时数组；不是纯快权重大小，也不是全部原生工作区或最坏界。没有内存支配主张。全部费用和元数据见[真正冷启动资源](../../results/shared_mode_readout/resources/summary.json)。

本轮的进展是：新增解释的独立查询价值已被测到；同读出下短预算局部ALM也给出有竞争力的开发均值。下一步不能继续把128轮等待成本掩盖掉，或事后选择ALM16当成功主候选。具体机制改进转向[251局部分支能量触发的乘子跃迁](251_local_dual_jump_design.md)：先证明一个可在非停滞状态直接检验的条件分支切换，检验能否提前产生当前第128轮才出现的解释，再考虑完整预测和费用；强活动跳转、BP和回归对照继续保留。

核心目标保持active。本轮有正向因果证据，但不是最终独立论文级任务优势。
