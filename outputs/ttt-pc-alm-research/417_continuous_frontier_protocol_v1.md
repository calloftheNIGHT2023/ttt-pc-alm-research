# 417｜连续支持搜索与可中断前沿预测：实现及预检协议

2026-09-25。此版本实现新接口，不改405主预算或413／414冻结证据。先进行完整257查询的正确性、归因接口与真实worker预检；不读取查询答案，不宣称任务风险已改善。后续正式限时比较必须另冻协议并保留405全部42个控制。

## 1. 正向假设及完整交付路径

在共同支持与先验下，完整模式搜索未结束不等于没有预测信息。413／414已给出覆盖剩余所有可行参数的范围。将该范围在实际截止前交付，可能减少405中“只有初始备用预测”的损失。需要检验的独立乘子贡献是：相同范围读出下能否更早得到更紧且安全的覆盖，而不是通用区间投影本身。

在线输入仅x、v、q、公开读出随机种子与固定配置。每次从头计算：

1. 共同prior4096岭回归备用，立即发送完整查询向量；构造与读取成本均收费。
2. 计算全部查询的Lipschitz-16支持包络，向外舍入后投影备用，再发送。
3. 除cheap_only外，新运行同一DFS／farthest-x搜索，默认合作式上限0.25秒、最多65536展开。这不是整体硬截止保证；singleton构造和单批求解均可能越过合作边界。
4. 若搜索完成，先付费执行原共享几何／2048粒子读出；仅完整集合已分类且读出可用时采用该预测，并作廉价包络投影。完整模式中的数值几何含全局LP，不称全流程局部算法或精确Bayes。
5. 若搜索未完成或完整几何未解决，先从新生成的搜索状态构造414的精确坐标盒。复用这些盒而不重跑搜索；分批处理32个查询，每批将对应坐标投影到安全区间，发送完整向量，未处理坐标保持廉价预测。全部257查询完成后才发送final。

查询遍历顺序：按可观察输入值稳定排序，再按排序位置的二进制位反转次序遍历；不依赖答案，避免先只覆盖网格左端。它不改变支持搜索、最终逐查询范围或最终预测；中间包随实际完成数变化。保留每批索引、范围、交付时间和预测。

## 2. 数学保证与浮点交付

设全部相容参数输出被精确区间I_j覆盖。真实参数相容时，真输出y_j属于I_j。对端点向外舍入得到浮点区间J_j⊇I_j；用浮点clip得到的p_j是原浮点预测r_j在J_j上的精确实数投影。因此

    (r_j-y_j)^2 - (p_j-y_j)^2 >= (r_j-p_j)^2 >= 0。

这里比较生成函数值；若评估标签含额外噪声，只能在另行说明的条件均值／期望意义下推广。不能把支持相容条件省略。分批中未处理坐标不变，所以每个完整向量中间包仍满足逐坐标非增保证。保证相对于被投影的共同备用／廉价预测，并不自动说明新候选优于强BP。

binary64最近舍入不足以保留包含。每个下端点须满足Fraction(float_low)≤exact_low，上端点相反；若不满足，用nextafter向外移动，并复核。包括非二进制有理数、subnormal、0／1和零宽区间。零体积但非空盒保留。没有非空覆盖时明确报错，不伪造正确性。

## 3. 完全共同的读出控制

新接口包含active512、passive512、instant512、PDHG-cold512、PDHG-box512、none，以及cheap_only。

- passive不将乘子反馈到原变量更新，但仍累积乘子产生证书，不得称为“没有乘子”。
- instant不积累乘子，仅用即时残差等候选信用；用它检验积累信用的必要性。
- none只用已有简单区间收缩与相同搜索调度。
- cheap_only不给范围搜索收费，也不获得搜索范围；它检验不用搜索的廉价包络是否已足够。

instant512已由冻结底层求解器支持，但旧registry未列出。新版本用有恢复保证的局部配置作用域暴露它，不能编辑原registry或污染后续旧方法。新worker只为frontier种类加载此接口；旧42种配置直接调用402worker，不改变其预加载修正、计算或截止接收规则。控制器仍沿用387的Session.run。

未来强优化器也可以与同一证书模块组合，但必须从同信息的新付费搜索产生覆盖；不能把候选的前沿免费送给对照，也不能把普通优化器找到的若干点误称为全部可行参数覆盖。
