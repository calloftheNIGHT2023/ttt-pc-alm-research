## 2. 三个领域与两级覆盖

下表中的模型大小与任务形式是本项目的候选设计，不是数据集作者的默认设置。首轮以可重复、可审计的小模型为主，不依赖 LLM / VLM 大规模训练。

| 领域 | 第一主任务 | 第二扩展任务 | 小模型候选与希望检验的变化 |
| --- | --- | --- | --- |
| NLP | CLINC150 少样本意图分类 | BANKING77 少样本意图分类 | TextCNN → 2–4 层小 Transformer；检验不同文本表征与细粒度意图区分下的适应 |
| CV | CIFAR-FS 少样本图像分类 | miniImageNet 少样本图像分类 | Conv4 → ResNet-18；检验自然图像类别变化与更深特征提取器 |
| Graph | FS-Mol 少样本分子图分类 | ogbn-arxiv 少标签节点分类／时间划分扩展 | 3–5 层含键特征的 GNN → 2–3 层 GraphSAGE / GCN；同时覆盖图级和节点级预测 |

数据来源已经核对：CLINC150 官方库提供意图与 OOS 数据；BANKING77 官方库提供银行意图数据。这里设计的 class-disjoint 少样本 episode 不是它们原始划分自动包含的标准协议，必须单独公布类别清单和样本清单。[CLINC 官方仓库](https://github.com/clinc/oos-eval)、[BANKING 官方仓库](https://github.com/PolyAI-LDN/task-specific-datasets)。

CIFAR-FS 与 miniImageNet 优先沿 R2-D2 官方少样本数据与划分入口复用，并保留该方法作为强闭式适应对照。[R2-D2 官方仓库](https://github.com/bertinetto/r2d2)。

FS-Mol 使用官方 train / valid / test assay 列表与评估接口；保留官方 kNN、随机森林、原型网络等相关强对照。ogbn-arxiv 有官方时间划分，但将其改成少标签在线适应是我们的扩展协议，不能直接称官方榜单结果。[FS-Mol 官方仓库](https://github.com/microsoft/FS-Mol)、[OGB 官方说明](https://ogb.stanford.edu/docs/nodeprop/#ogbn-arxiv)。

模型配置只在训练／验证数据上选取；不能因为测试结果不利就无记录删除某一领域或换数据集。数据下载前检查许可、版本、样本重叠及去重规则。

## 3. 统一任务接口与信息边界

每个 episode 含先观察到的支持序列 S 和后续查询 Q。所有方法获得相同支持顺序、样本及已公开的标签；每个查询先封存预测，再由独立评估器读取答案。任务结束重置快状态，不能跨测试任务积累标签。除预先声明的流式协议外，查询样本不能回流成为支持。

- NLP / CV 初始候选为 5-way，1 / 5 / 10 / 20-shot；支持按前缀逐步出现，每个前缀预测独立留出的查询。类别、划分和 episode 清单在最终测试前冻结。
- FS-Mol 优先沿官方支持采样与评价设置，候选支持总数 16 / 32 / 64，保留真实类别不平衡。不能把它和“每类 K-shot”混报；单类支持或指标不可定义时的处理必须预先规定且适用于所有方法。
- ogbn-arxiv 明确采用传导还是归纳设置。若允许整个无标签图及查询节点特征，所有方法同样可见；不得让查询标签进入消息传递、特征处理或模型选择。时间流扩展还要冻结每时刻可见节点／边，不能提前使用未来结构。
- 这里的首批任务是“带标签示例作为已观察上下文”的少样本适应，不自动等于“完全无标签的自监督 TTT”。若后续声称后者，须另冻仅从已观察输入构造 key/value 或重建目标的任务，先验证该自监督目标与下游预测的联系，不能混用两种信息制度。
- 原官方 TTT 的 key/value 目标、支持标签编码、query 读取以及外层训练预算须明确实现；不能把普通 BP 微调重命名为官方 TTT，也不能拿旧分布随机／不匹配权重充当强对照。

## 4. 同一机制如何进入真实模型

第一层是受控桥接：真实文本、图像或图的编码器产生表征，小型多层非线性适应块消费真实支持；验证共同目标、截止时间和独立查询风险的关系。它能检验机制进入真实数据，但单独完成这一层还不足以支持“内部多层参数适应”的主张。

第二层必须真正进入小模型内部：优先 TextCNN、Conv4、固定图结构的 ReLU 消息传递网络，在至少两个内部层的偏置／低维偏置基上适应；所有 BP / PC / PC-ALM 控制使用完全相同的参数位置、初始化与目标。在线变量维数先从小规模逐步增加，参数数目、基的外层学习成本和求解器状态分别计账。需要测完整输出是否改变，特别检查后续归一化是否消去新增方向。

当前区域证书仅能在其数学条件成立时使用：固定线性映射、对适应变量的仿射注入、分段仿射活动可给定模式下的仿射约束。冻结统计量的 BatchNorm 可作为固定仿射运算处理；输入依赖的 LayerNorm、注意力 softmax、GELU，以及同时更新一般权重产生的双线性关系，不能未经新推导当成原多面体问题。Transformer / ResNet 扩展必须明确其适应位置及完整后续路径，重新证明或明确记录近似误差。

不允许把“真实编码器 + 原四维合成教师”当作真实任务；目标必须来自真实数据标签／可观察自监督信号。也不允许默默把证书方法换成普通 PC-ALM 更新后仍沿用证书带来的收益解释。

跨领域要检验的同一正向假设是：支持样本留下多个兼容内部解释时，局部乘子引导的安全排除降低找到有效适应／预测状态的成本；在规定预算内，这种成本改善能够转为未见查询质量改善。具体数据上是否存在这一结构要在开发划分上检查，不能通过最终测试标签挑选“有利 episode”。

## 5. 分类任务与当前风险推导的连接

设查询标签的 one-hot 向量为 e_Y，m = P(Y | S, q)，a 是交付的类别概率向量。这里 q 包含该协议允许看到的全部查询侧输入；例如传导图任务需条件于允许可见的图与节点特征，不仅是单个节点。条件 Brier 风险满足：

    E[||a - e_Y||² | S, q] = ||a - m||² + 1 - ||m||²。

因此对共享备用 r 和完整预测 p，定义 Delta = ||r-m||² - ||p-m||²。两种只在预算内完成指标 I 上不同的策略满足：

    Risk(C) - Risk(A) = E[(I_A - I_C) Delta]。

这使“更早取得有效预测”的数学判断可在分类概率上直接检验。有限近似 p 并不自动等于 m；不同方法输出不共享同一 p / r 时必须重新分析，不能硬套上式。Brier 改善也不自动推出 accuracy、F1 或 AUPRC 改善，所以真实任务指标另行实测。

该恒等式是本计划的直接推导，不是已经证明真实数据满足机制前提。将条件对齐并获得相应实测收益，才构成理论—模型证据链。

## 6. 强对照与归因

所有领域保留无适应、固定特征线性 LS / 岭 / 流式 RLS、固定非线性特征／核回归、元学习岭回归、浅层非线性头，以及相同内部适应范围和目标的 BP / 普通 PC / PC-ALM。分类还要有适当的逻辑回归／原型对照；Graph 保留领域强基线。闭式解的正则化和特征维数也须有公平的验证集调参预算。

必须同时比较“主方法 + 新模块”和“同一模块 + 强 BP / PC / 简单求解器”；另比较线性残差头，防止重现原 A 扩展被线性头完全解释的问题。共同先验、数据暴露次数、读出与缓存规则保持一致或清楚分层。需分别记录主动反馈、乘子、证书验证及多解释读出的消融，不能把新增容量与 PC-ALM 的贡献混在一起。

官方 TTT 优先复用现有官方源码；其外层 BP 可以使用，但与其他可学习先验的训练标签数、任务数及算力分别统计。主候选推理时若声明无全局 BP，就不得以 BP 信用初始化乘子或先运行一遍 TTT 反传。

## 7. 资源、统计与完成标准

- 主要任务指标：NLP / CV accuracy 与 macro-F1；FS-Mol 依官方评价约定报告 AUPRC 等；节点任务 accuracy。共同机制指标为 Brier／相应回归风险及支持前缀学习曲线，另报 NLL 与校准。
- 同时比较固定在线时间、固定峰值状态上限下的质量及完整质量—成本曲线。记录编码、支持更新、搜索／求解、读出、传输、冷启动、预热、重建与清理，不能只计更新核或只比较参数量。
- 公共缓存只能包含在该适应范围下仍有效的量；内部更新后失效的特征必须重算并收费。GPU 计时需同步并计未完成核；不假装到期就能无成本撤销已提交计算。
- 初步至少三个独立外层训练种子，确认阶段样本数根据开发方差及事先定义的实际收益阈值确定。按独立任务／assay 做配对与聚类统计；同一图反复抽节点不能假称多个独立图，训练种子不能用大量相关 episode 冲淡。
- 在最终测试前固定每域主配置、主要预算、主指标、主要对照与多重比较处理。报告全部预算和全部预列任务，不只报最有利曲线；超时／失败纳入预定规则。
- 三域真实小模型验证是完成要求；每域至少一个主任务和一个扩展任务按冻结方案交付。是否支持“跨领域独立优势”取决于预列对照、实际任务指标和机制消融，不由“六个脚本跑完”决定。
