# 449｜真实任务验证：NLP / CV / Graph 上的 TTT×PC-ALM

2026-09-26，Claude Code。承接 448（端到端训练的 TTT×PC-ALM 层）。目标：检验 TTT 与 PC-ALM 结合的有效价值在真实数据、真实标签（或真实物理测量模型）与真实小模型编码器上是否成立。

## 1. 为什么这样设计真实任务

普通的真实标签少样本分类（例如区分两个类别）是近似单调、线性可分的关系。C2 已经证明这类任务上闭式头最好，PC-ALM 没有优势，也不应该有。要检验 TTT×PC-ALM，真实任务必须同时满足：

1. 标签与某个方向之间是非单调、多分支的关系；
2. 这个方向每个任务都不同，而且外层训练时没见过（外层无法提前背下）。

## 2. 三个领域的任务

- **NLP：** MRC 心理语言学数据库（真实人工评分与语料统计）。单词表示用 GloVe-300（MiniLM 的可解码性太低，见 §4）。
  - 每个序列随机选一个属性 j，给出 n 对单词及其差值绝对值 |attr_j(a)−attr_j(b)|，也就是“两个词在属性 j 上差多少”。
  - 外层只在 7 个训练属性上训练（字母数、音素数、音节数、熟悉度、具体性、可意象性、有意义度）。
  - 测试用 5 个从未见过的属性（KF 书面词频、KF 类别数、KF 样本数、Thorndike-Lorge 词频、习得年龄）。
- **Graph：** QM9 的 13 万个分子，19 个真实量子化学属性。
  - 4 层 GINE 编码器只用 14 个训练属性训练，然后冻结。
  - 任务形式同 NLP。测试属性为 μ、gap、Cv、R²、B，编码器与外层都没见过。
- **CV：** CIFAR-10 真实图像（灰度 32×32）的压缩相位恢复。
  - 每个序列对应一张图像；上下文为随机高斯测量向量及幅值 |a·x|。测量是模拟的物理模型，不是实拍数据。
  - 外层在训练集图像上学一个 64 维图像基，评估只用测试集图像；测量次数远少于 1024 个像素。

## 3. 模型（同一数据、同样训练 3000 步）

- TTT×PC-ALM：内部记忆为 |w·k|，逐样本两分支闭式反演，加乘子与局部最小二乘；ρ 固定为 1（448 的教训）。
- TTT 梯度：全批量与官方单遍两种。
- TTT 闭式：线性岭回归，以及二次特征岭回归（预测 y² 再开方，恰好能表示 |u·k|，即“固定非线性特征＋闭式头”）。
- Transformer：4 层。

参照项：
- NLP/Graph：用该属性的全部标注训练的线性探针。它不是少样本方法，只表示线性可解码性的上限。
- CV：用训练图像 PCA 基加 PC-ALM 的参照，以及“真实图像投影到 PCA 子空间”的误差下限。

## 4. 执行中的调整（均基于数据的可解码性，不看任何方法的结果）

1. **MiniLM 词表示：** 13 个属性的 R² 只有 0.28–0.62，全标签线性探针预测 |Δ| 的 NMSE 为 0.84–1.21，任务没有信号，因此换成 GloVe。
2. **GloVe 下重新划分测试属性：** 原测试集中可意象性、音节数、口语词频的探针 NMSE 为 0.98–1.31，不可用。改为留出整个可解码的词频簇（探针 NMSE 0.50–0.60）加习得年龄（0.75–0.78）作为测试；口语词频与词频簇重叠且解码性差，去掉。
3. **CV：** 64 维子空间外的残余能量使 NMSE 存在约 0.06 的下限，因此不再使用“NMSE<0.05 算成功”，直接比较 NMSE；内迭代 K=100（校准时 K=100 与 K=200 结果一致）。
4. **QM9：** Cv、gap、R² 的可解码性高（R² 0.87–0.98），B 中等，μ 较差（0.47），保持原划分。

## 6. 解读

1. **CV 在基固定时出现了 TTT×PC-ALM 的真实优势。**
   - 同一个 PCA 基下，PC-ALM 内更新在 4m 和 6m 时的 NMSE 为 0.136 和 0.100，GD 内更新为 1.1–1.6，二次闭式为 0.83–0.87。
   - 在 4m 和 6m，它也优于所有学习基的方法，包括 Transformer（0.27）和二次岭（0.24–0.26），并接近 0.067 的投影下限。
   - 失败只出现在低采样端：2m 完全失败，3m 的均值 0.43、中位数 0.12，说明是部分序列失败。这是“从随机初值做精确反演”的初始化缺口。
2. **NLP/Graph 上 TTT×PC-ALM 没有赢。**
   - v2 的 PC-ALM 接近常数预测（约 0.98–1.09）。
   - GD+校准与二次闭式分别达到 0.73 和 0.88。
3. **缺口诊断：噪声在 |·| 里面。**
   - 真实属性只能部分线性解码（探针 R² 约 0.5–0.9），所以真实标签是 y = |u·k + ε|，其中 ε 是编码里不可解码的残差。
   - CV 同理：64 维码之外的图像能量 a·x⊥ 也在 |·| 里面。
   - 原 PC-ALM 的局部反演、乘子与读出都假设 y = |u·k| 精确成立：
     - 硬分支选择把噪声原样复制进活动变量，也无法降低低置信分支的权重；
     - 约束不可满足时，乘子（DR 主序列）持续漂移；
     - 读出用 |w·k|，而不是条件期望 E[y|k]。
   - 这个缺口在 450 中修复。
