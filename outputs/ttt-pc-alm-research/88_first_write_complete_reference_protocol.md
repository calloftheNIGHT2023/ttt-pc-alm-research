# 88. 首次写入的完整模式参照：先计算遗漏质量，再设计机制

本协议先于参照实验结果。第86轮规范读出后，ALM与Adam的后续三阶段预测相同，主要质量差异集中在4上下文首次写入。下一步需要回答的不是“哪个方法拟合得更低”，而是“它找到了完整条件分布中的哪些有效解释、遗漏了多少”。

## 有限、可核验的参照算法

当前每层帐篷函数4个仿射分支、4层、4观察，朴素全组合为4^16。先对每个观察单独列举4^4=256条路径，再逐观察求可行路径集合的交集。模式决定了输出和所有分支边界关于4个偏置的仿射不等式；不同观察共享同一偏置。按单观察剩余路径数升序交集，仅改变遍历顺序，不改变问题。

每步采用共同安全区间收缩与全局LP辅助分类。LP给出候选非负乘子 λ；用精确二进制有理数验证

    d(λ) = −λᵀr − 0.12 ||Aᵀλ||₁ > 0

才允许因此排除 A b≤r、b∈[-0.12,0.12]^4。证明：盒上 min λᵀ(A b−r)=d(λ)>0，与可行点各不等式非正矛盾。即使LP未收敛或判断接近零，也保留该分支；不能把没有正体积数值内点直接当作严格不可行。精确证书包含模式、观察编号、稀疏乘子和有理数下界，允许独立重验。

最终区域体积仍沿用原浮点LP/凸包几何；若有最终数值几何未解决项，或遍历触及预算，必须标为不完整，不给出“完整后验覆盖率”。精确剔除与数值积分是两种不同保证。参照使用全局优化，不是PC-ALM方法、更不是新闭式头下界。

## 冻结范围

旧开发16流5900000—5900015，仅首次4上下文，不生成查询输入或答案。每任务最多50000次分类LP、180秒分支搜索；最终已留下区域的几何计算另外计时。参照总成本只作诊断成本，不冒充在线方法成本。

比较第86轮六类首次写入器：ALM20、Adam60、Adam240、直接几何R128、零乘子精确块20、局部梯度PC80。全部首次使用F256；用原冻结源和同一几何，不改变算法。若完成参照，报告每算法的正体积模式数、发现质量/参照总质量、缺失模式列表和互补模式；暂不评估查询收益。

预先判断：只有出现ALM在匹配有限预算下稳定保留更重要模式的证据，才为此设计新的模式保留/发现机制；若各法质量覆盖相近，就不能继续用“ALM找到更多模式”解释当前微小查询差异。这个参照能帮助定位要改进的具体步骤，不改变主研究目标，也不消耗预留新确认流。
