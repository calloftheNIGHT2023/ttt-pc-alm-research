# 407｜同一端到端目标下的局部更新原语

2026-09-25。仅为后续统一目标消融准备，不修改正在运行的405。旧算法和证据保留。下面的数学检查不是新任务收益，也不代表 PC-ALM 独立贡献已经成立。

## 1. 统一目标，而非仅统一可行集

对每个支持观测 v_i，令 B_i=[max(0,v_i-epsilon),min(1,v_i+epsilon)]，要求非空。固定 tau>0，定义

    ell_tau(y_i,v_i) = dist(y_i,B_i)^2 / (2 tau)
    J(b) = (1/n) sum_i ell_tau(f_b(x_i),v_i),  b∈[-.12,.12]^L。

当tau=1且网络输出在[0,1]时，该J就是现有BP的平均平方带状违约目标。BP的链式梯度、局部PC、局部ALM和去乘子控制必须针对这个同一目标与同一参数盒；历史最优点也应按同一J选择，而非一方按均方、一方按最大残差选。

引入活动h_li与约束 r_li=h_li-g(h_(l-1)i+b_l)，h_0i=x_i，h_li∈[0,1]。缩放乘子u=lambda/rho下增广目标为

    A(b,h,u) = (1/n)sum ell_tau(h_Li,v_i)
               + (rho/n)sum_(l,i) [u_li r_li + r_li^2/2]。

rho是约束罚系数，tau是共同任务目标的一部分；不能只为某个求解器改tau。PC固定u=0，ALM更新u；它们有共同原始约束问题，但有限rho、有限迭代的松弛误差仍需报告，不能称中间状态的所有标量目标完全相同。

## 2. 精确输出活动更新

设a=g(h_(L-1)+b_L)-u_L，之前输出活动为h_old，非负近端稳定系数t。更新需最小化

    ell_tau(h,v) + rho(h-a)^2/2 + rho*t*(h-h_old)^2/2,  h∈[0,1]。

定义kappa=rho(1+t)、c=(a+t*h_old)/(1+t)、p=clip(c,B)。无[0,1]限制时的唯一极小点为

    h_star = (kappa*tau*c + p)/(1+kappa*tau)，

再投影到[0,1]给出约束极小点。证明可在B左、内部、右三个二次区间直接求导；外部截断由一维严格凸性给出。tau→0时趋于硬带投影，但tau=1时一般不同。

因此现有硬投影并不是同一有限tau损失的精确局部更新。这个变化是统一目标所需的实现修正，不是凭公式就有新的查询收益。

## 3. 局部导数与信用对应

记c_li=u_li+r_li。在非折点处，偏置偏导只需本层信息：

    dA/db_l = -(rho/n) sum_i c_li g'(h_(l-1)i+b_l)。

活动偏导只依赖相邻层：内部层为rho/n乘以 `c_li-g'(h_li+b_(l+1))*c_(l+1)i`；最后一层再加ell_tau的导数/n。候选实现不得为初始化u先运行全局BP；共同初始化仍是u=0。

在约束满足且活动驻点成立、适当处理活动边界法锥的条件下，lambda_L=-ell_tau'，lambda_l=g'_(l+1)*lambda_(l+1)，偏置梯度等于端到端链式梯度。测试可单独构造这个驻点信用作为诊断，但该构造不能被放入候选初始化。这只验证信用计算，不推出有限步速度或泛化优势。

## 4. 后续归因必须分开的因素

至少包含：局部梯度PC／局部梯度PC-ALM，以及精确局部块去乘子／精确局部块ALM。否则“普通PC梯度步 vs ALM局部精确求解”同时改变两项，不能仅归因给乘子。BP Adam/GN使用相同J、起点、参数盒、支持信息、选择规则与读出。正则项若增加，也必须所有控制一致。活动、乘子、优化器矩和局部求解器临时状态全部计入资源。

当前只实现Fraction标量近端与局部偏导原语及独立检查；尚未替换任何实验优化器。预设检查包括：分段二次枚举的独立极小值、KKT符号、局部偏导的精确有限差分，以及约束满足时与独立全网络有限差分的一致性。另保留硬投影和有限tau近端不相等的明确例子。测试等405整条链终结后运行，避免干扰限时计量。
