## 1. 流式 TTT（J）：GAMP 一类在两个状态组都占优

He₃ 单指标，d=64，每块内迭代 10 次，每档 64 个任务。有界状态组的超参数只按“先预测新块、再更新”的累计预测损失选择。表中为成功率：

块=64 时，GAMP 回放在 3d 为 0.94、4d 为 1.00；PC-ALM 回放在 5d 为 0.78、7d 为 1.00；小批量 AMP 在 6d 为 0.89、8d 为 1.00；PC-ALM-RLS 与官方 TTT 始终为 0。

**结论：**

- 回放组里，GAMP 达到 90% 所需的上下文约为 PC-ALM 的 2/3，最终两者都到 100%。
- 有界状态组里，只保存高斯后验的小批量 AMP 能学会；PC-ALM 冻结早期块的活动后，错误分支持续污染估计，完全失败。
- 流式设定**没有**给 PC-ALM 带来优势，预测 J 中“PC-ALM-RLS 可能有竞争力”不成立。
- 与原研究问题直接相关、且稳定成立的是：官方 TTT 梯度内循环在这类任务上始终失败，而带残差记忆的提升式内循环能成功（GAMP 与 PC-ALM/DR 都能）。

## 2. 深层多分支（I）：PC-ALM 首次与 GAMP 相当或更好，但结论待算力对齐确认

模型：y=|a₁He₃(w₁·x)+a₂He₃(w₂·x)+b|+σε，W、a、b 全部未知。

执行中的两处修改，已记录：

1. He₃∘He₃ 的 9 次复合在冒烟测试中对所有方法（包括 GAMP 神谕）都不可学，因此外层改为 |·|。
2. 原先逐单元 Gauss–Seidel 的 PC-ALM 发散（|a| 从 2 增到 50）。改为每样本在 (s₁,s₂) 上做二维全局联合求解（与 GAMP 的二维后验网格对等），第二层罚参数 ρ₂∈{10,30} 按支持损失选择，同 ρ 无乘子对照用同一网格。

深层 PC-ALM 的层间约束是非线性的，**不等价于 DR**，是 PC-ALM 唯一可能拥有独立身份的设定。

每格 16 个任务，表中为成功率 / 第一层子空间重叠（总耗时）：

| 方法 | d=16，α=8 | d=16，α=16 | d=32，α=8 | d=32，α=16 |

| PC-ALM 深层 8×2 ＋ Adam 细化 | 0.06 / 0.72（108 s） | **0.62 / 0.95**（193 s） | 0.00 / 0.57 | 0.44 / 0.90（174 s） |
| PC-ALM 深层 8×2（不细化） | 0.00 / 0.69 | 0.06 / 0.95 | 0.00 / 0.57 | 0.00 / 0.88 |
| 同 ρ 无乘子 8×2 | 0.00 / 0.44 | 0.00 / 0.55 | 0.00 / 0.29 | 0.00 / 0.41 |
| GAMP 神谕（已知 a,b）＋ Adam | 0.06 / 0.89 | 0.44 / 0.89（15 s） | 0.00 / 0.84 | **0.50 / 0.94**（14 s） |
| GAMP 网格 60 点 ＋ Adam | 0.12 / 0.90 | 0.38 / 0.90（45 s） | 0.06 / 0.78 | 0.25 / 0.89（42 s） |
| BP Adam 64×3 | 0.00 / 0.49 | 0.00 / 0.73 | 0.00 / 0.44 | 0.00 / 0.60 |

**初步观察：**

- α=16 时，不知道 a、b 的深层 PC-ALM，与知道 a、b 的 GAMP 神谕相当，并好于实用的 GAMP 网格。
- 乘子仍是关键：有乘子重叠 0.88–0.95，无乘子 0.41–0.55。
- 注意事项：
  1. PC-ALM 用了约 4 倍计算；
  2. 两类方法都要靠 Adam 细化才能过阈值；
  3. 每格只有 16 个任务；
  4. GAMP 用的是对角方差近似，不是完整的 2×2 委员会 AMP；
  5. 网格只有 60 点。

  因此补做两档算力对齐（v3，每格 32 个任务、新种子）：低档是 PC-ALM 2 起点 对 GAMP 网格 60 点，高档是 PC-ALM 8 起点 对 GAMP 网格 240 点。结果见第 3 节（运行中）。

## 4. 修正后的研究主线（建议）

1. **稳定成立的主结论**，也是对原研究问题的回答：在高维多分支的上下文适应中，TTT 的梯度内循环、BP 与固定特征闭式头在 n=O(d) 时都失败；把内循环换成“逐样本局部反演＋残差记忆”的提升式方法可以成功，而且记忆项是因果上必需的。
2. **单层时**，PC-ALM 就是近端 DR；它相对 AMP 类（GAMP、小批量 AMP）没有优势，在编码衍射上与 RAAR 持平。论文应把 DR/ALM 与 AMP 写成同一机制的两种实例，并给出何时哪种更好的证据（随机设计时 AMP 更好；有界状态流式时 AMP 更好）。
3. **PC-ALM 可能的独立贡献**只剩深层非线性约束，以及证书路线；深层的正面信号要在第 3 节的算力对齐结果成立后才能写。
