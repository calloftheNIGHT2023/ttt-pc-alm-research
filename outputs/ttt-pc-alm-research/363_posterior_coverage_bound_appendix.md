# 363 附录｜为什么有效分支覆盖可能影响查询预测：一个有条件的风险界

写于363固定方法的预测运行期间；不改变主方法、预算、排序、读出或评价规则。以下是标准条件均值分解，不是PC-ALM专属定理，也不回填为执行前的查询收益预测。

## 1. 分支数不是最终数学对象

在观察到支持上下文D后，设已明确指定的工作后验为Π(θ|D)，预测f_θ(q)∈[0,1]。选择若干可行区域的并集S，保留质量α=Π(S|D)>0，遗漏质量ε=1−α。令

    m(q) = E_Π[f_θ(q)|D]
    m_S(q) = E_Π[f_θ(q)|D, θ∈S]
    m_out(q) = E_Π[f_θ(q)|D, θ∉S]。

由条件期望分解，m=αm_S+εm_out。因此

    |m_S(q)−m(q)| = ε |m_S(q)−m_out(q)| ≤ ε
    E_q[(m_S(q)−m(q))²] ≤ ε²。

若ε=0，约定m_out无须定义且两预测相同。若α=0，则条件后验m_S不存在，必须显式使用回退方法，不能套用这个界。

## 2. 何时这真的是查询风险界

只有当评估中的条件目标均值确实等于m(q)，并且平方损失的条件二阶矩存在时，条件Bayes风险分解才给出

    R(m_S|D)−R(m|D) = E_q[(m_S(q)−m(q))²] ≤ ε²。

若工作先验、观测噪声模型或任务分布错配，该式中的风险优势结论不自动成立；前面的两个条件均值之间的近似界仍成立，但目标是工作后验而不是必然的真实最优预测。

S⊆S′⇒Π(S′|D)≥Π(S|D)，故上述**上界**不增。但对某个固定教师、实际有限查询集，甚至对两个不同截断近似的实际Bayes超额误差，都不保证误差单调下降：新加入区域可能把条件均值暂时推离完整均值。

一个可手算的反例：三种有界预测为0、2/5、1，工作后验质量为1/5、3/5、1/5，完整均值11/25。先只保留2/5，则超额误差1/625；再加入预测0的区域，截断均值变成3/10，超额误差49/2500反而更大。与此同时，遗漏质量平方上界从4/25降到1/25。它说明“上界改善”和“每个实际近似都改善”是两种不同命题，不否定前面的上界。

## 3. 有限粒子读出必须另计

若使用N个真正独立的条件后验样本，则有条件于D、q的无偏样本均值估计满足

    E_samples[(m_hat_S(q)−m(q))²]
      = (m_S(q)−m(q))² + Var_Π(f_θ(q)|D,S)/N
      ≤ ε² + 1/(4N)。

当前程序按区域体积和固定分配进行粒子读出，不应未经证明称为上述独立同分布采样。因此本轮不把1/(4N)直接当作实际程序的保证。一般只能另加经证明或测量的采样/数值误差项。

## 4. 对当前候选机制意味着什么

362证明原先可行前缀的集合包含关系；它若增加了后验质量而不只是几个极小区域，才会减小这个截断误差上界。于是完整可检验链条应是

    信用更早给出前缀严格证书
      → 固定计算预算可访问更后面的可行区域
      → 保留工作后验质量增加
      → 截断预测误差上界减小
      → 在实际任务和采样/资源约束下验证查询收益。

每个箭头都有独立条件；不能把“证书更多”或“正区域数25比19多”直接替换为最右边。

当前C20-all只是数值几何找到的完整**剩余必要候选池**，包含原母正区域。零体积/未判空分类、数值体积和有限粒子均有边界，不是已经证明精确的全参数Bayes后验。即便随后用其体积计算相对遗漏质量，也只能先报告“相对于此有限、数值工作后验的覆盖”，不能冒称全局统计保证。
