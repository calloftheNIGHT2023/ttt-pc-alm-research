# 官方 TTT 桥接与资源审计

## 1. 现在可以坚持的数学结论

当前任务族已经满足“在明确资源条件下，数学上比闭式头或再加一层更强”，但不能写成无条件支配一切闭式方法：

$$
F_{\mathbf a}=T_{a_L}\circ\cdots\circ T_{a_1}
$$

用 $3L$ 个深层 ReLU 单元和 $L$ 个 episode 参数即可精确表示；任意单隐层标量 ReLU 网络若要精确表示同一函数，宽度必须满足

$$W\ge 2^L-1.$$

更强地，在构造出的 $2^L+1$ 个独立交替标签查询点上，宽度 $W$ 的单隐层网络错误率至少为

$$
\frac{\max\{0,\lceil(2^L+1-W-2)/2\rceil\}}{2^L+1}.
$$

因此取相同数量级的 $W=3L$ 时，浅层下界趋近 $1/2$，深层组合误差为零。若先有一个带 $K$ 个折点的冻结表示，再加宽度 $W$ 的一层网络，则精确表示的必要条件是

$$
(W+1)(K+1)\ge 2^L.
$$

OLS、ridge、RLS 或固定 ReLU 特征上的其他闭式求解器只改变系数，不产生新折点，所以也受同一固定函数空间限制。任意核不在这个无条件结论内：若把目标结构或指数多特征预编码进核，它当然可能成功，但相应先验、中心、Gram 状态与求解成本必须计入。

这是一条函数类和资源分离结论。它证明“为什么有必要研究内部组合适应”，不证明 PC-ALM 比 BP 更优。

## 2. 官方 TTT-MLP 到底更新什么

固定的官方 PyTorch 代码为 [`test-time-training/ttt-lm-pytorch`](https://github.com/test-time-training/ttt-lm-pytorch) commit `cd831db10c8c9a0f6340f02da5613316a8a92b67`。单头记号下，快学习器为

$$
Z_1=X_KW_1+b_1,\qquad
Z_2=\operatorname{GELU}(Z_1)W_2+b_2.
$$

它的内层重构目标是

$$R=X_V-X_K,$$

损失通过带可学习仿射参数的 LayerNorm 作用在 $Z_2$ 上。官方实现显式计算 $\partial\ell/\partial Z_2$，再按链式法则得到

$$
\frac{\partial\ell}{\partial Z_1}
=
\frac{\partial\ell}{\partial Z_2}W_2^\top
\odot\operatorname{GELU}'(Z_1),
$$

并更新 $W_1,b_1,W_2,b_2$。随后用更新后的快权重读取 $X_Q$，输出残差形式

$$X_Q+\operatorname{LN}(\operatorname{MLP}_{\theta'}(X_Q)).$$

因此原始 TTT 并不是“看到显式任务标签后拟合 $x\mapsto y$”的普通回归头。当前 tent 原型的监督式 $(x_i,y_i)$ 内层目标若未经桥接，不能冒充原始 TTT 对照。

## 3. 可执行机制审计

`work/experiments/official_ttt_smoke.py` 同时执行官方公开前向路径与底层快权重路径。固定随机种子的结果为：

| 检查 | 结果 |
|---|---:|
| 公开前向输出形状 | $2\times8\times8$ |
| 输出是否全部有限 | 是 |
| 单 episode 快参数数，$d=8,H=1$ | 552 |
| 解码梯度 carry 数 | 552 |
| $W_1$ 最大更新量 | 1.1667 |
| $W_2$ 最大更新量 | 0.9127 |
| 扰动 $Q$ 后输出最大变化 | 0.6673 |
| 固定 $K/V/\eta$ 时，扰动 $Q$ 导致的快权重最大变化 | 0 |
| 官方模块慢参数最大变化 | 0 |

最后两项把“写入”和“读取”分开了：在固定更新率的底层接口中，$K/V$ 决定快权重写入，$Q$ 负责读取。该结果只是机制复现，不是任务准确率证据。

## 4. 与因果 key/value 任务的公平桥接

### 4.1 输入协议

每个上下文 token 只含

$$z_i=(x_i,y_i,m_i=1),$$

查询 token 只含

$$z_q=(x_q,0,m_q=0).$$

测试查询真值只在 evaluator 内。编码器根据 mask 生成 $X_K,X_V,X_Q$；查询的 value 槽始终为零。不能把查询答案塞进 $X_V$，也不能用它选择内层步数、学习率或重启。

### 4.2 为什么必须有独立外层训练

官方 TTT 的 $Q/K/V$ 投影、快权重初始化、LayerNorm 和学习率门都是外层学到的。若把随机初始化的官方层直接放到 tent 任务上，再与手工知道组合结构的四参数模型比较，先验完全不匹配，结论无效。

下一阶段应使用互不重叠的三组 episode：

1. 元训练集：允许用其查询标签训练共享编码、初始化和超参数；
2. 验证集：只选超参数和停止步数；
3. 锁定测试集：仍使用 seeds 1000000–1000063，查询答案只评估。

所有方法必须得到同一批元训练 episode。强闭式基线不能只拿随机固定特征，而应至少加入“相同外层训练得到的冻结特征＋ridge/RLS/KRR”；否则差异可能只来自更好的先验。

### 4.3 必须并列的更新器

在完全相同的 $Q/K/V$、快参数范围、LayerNorm 目标与内层数据上比较：

- 官方 TTT 的梯度更新；
- 同一快参数上的 Adam/BP；
- 普通 PC；
- PC-ALM；
- 元训练冻结特征后的 ridge、RLS、KRR；
- 快状态不小于候选的可训练单隐层网络。

只有这样才能把“内部结构先验带来的优势”与“PC-ALM 信用规则带来的独立优势”分开。

## 5. 当前资源账

以下为 $L=4,n=16$ 的锁定实验；输入、目标、预测、逐元素临时量和框架开销未计。计数不是 FLOPs 或墙钟时间。

| 方法 | 最终预测状态 | 明确的适应辅助状态 | 结构化求解矩阵 | 更新/求解次数 |
|---|---:|---:|---:|---:|
| 内部 PC-ALM | 4 | 48 活动＋48 乘子 | 0 | $100\times8=800$ 活动 sweep |
| 内部普通 PC | 4 | 48 活动 | 0 | 800 活动 sweep |
| 内部 BP-SGD | 4 | 至少 64 个前向活动 | 0 | 100 次全局 BP |
| 内部 Adam-BP | 4 | 8 个矩＋至少 64 个活动 | 0 | 100 次全局 BP |
| 固定 ReLU ridge，$W=12$ | 14 个系数 | 0 | $14^2=196$ | 1 次线性求解 |
| RBF kernel ridge | 16 个系数＋16 个支持 key | 0 | $16^2=256$ | 21 个 $\gamma$ 候选 |
| 可训练浅层，$W=30$ | 62 | 3 重启的参数与 Adam 矩共 558 | 0 | $3\times500=1500$ 步 |
| 官方 TTT-MLP smoke，$d=8,H=1$ | 552 | 552 个梯度 carry | 0 | 按 token 在线更新 |

这张表否定了一个潜在的错误叙述：当前 PC-ALM 不是更省状态或更省迭代的赢家。它现在的价值是展示了不用全局反向信用也能在该内部结构上学习；是否在并行性、稳定性或硬件代价上胜出，尚无证据。

## 6. 进入下一轮的判定规则

下一轮的目标不是让 TTT 在随机初始化下输，而是检验经过相同外层训练后：

1. 内部组合先验是否仍显著优于元训练冻结特征上的强闭式回归和资源更大的浅层网络；
2. PC-ALM 是否在严格匹配的 TTT 快权重与目标上，取得 Adam/BP 不能解释的有限步收益；
3. 若官方 TTT、元训练核回归或 Adam/BP 已解释全部收益，则停止声称 PC-ALM 是新机制。

目前第一条在合成任务的数学函数类层面已经成立，在未做外层训练的在线原型上也有实证支持；第二条尚未成立。
