# 450｜噪声缺口与噪声校准的 TTT×PC-ALM

2026-09-26，Claude Code。承接 449（真实 NLP/CV/Graph 任务）。用户要求：把噪声滤掉，指出缺口并同时修复。

## 1. 缺口：噪声在 |·| 里面，原 PC-ALM 按无噪声设计

448 的任务满足 y = |u·k| 精确成立。449 的真实任务不满足：

- **NLP/Graph：** 属性只能部分线性解码（探针 R² 约 0.5–0.9），所以 y = |u·Δe + Δε|，其中 ε 是编码中不可解码的残差。
- **CV：** 64 维码之外的图像能量给出 y = |k·c + a·x⊥|，其中 a·x⊥ ~ N(0, ‖x⊥‖²)。

三个领域是同一个噪声模型：y = |s*|，s* = k·w* + ε，也就是噪声在绝对值里面（折叠正态）。

原 PC-ALM 每一步都假设 σ = 0：

| 环节 | 原 PC-ALM（σ=0 设计） | σ>0 时的后果 |
|---|---|---|
| 局部反演 | 在两个分支中硬选一个 | 噪声被原样复制进活动变量；|k·w| 小的样本分支后验接近 1/2，却被当成确定，错误分支以满权重进入 LS |
| 乘子 | λ ← λ + ρ(s − Kw) 累加直到约束精确成立 | 有噪声时约束 s = Kw 与局部损失不可同时满足；DR 主序列在不相容问题上发散（Bauschke–Moursi），乘子漂移 |
| 读出 | \|w·k_q\| | 对折叠正态有偏：E[y\|k] = E\|N(m, σ²)\| ≥ \|m\|，m→0 时差距为 σ√(2/π) |

另外，CV 在 2m/3m 的失败来自随机初值。那里的样本量处在相位恢复的门限附近，精确反演需要谱初始化一类的起点。

## 2. 修复：噪声校准的 PC-ALM（PC-ALM-σ）

每处修改都只替换上表对应的一环，σ→0 时逐项还原成原 PC-ALM，因此 448 的结论不受影响。局部问题不变：F(s) = (|s| − y)² + (ρ/2)(s − a)²，其中 a = k·w − λ/ρ；两个分支的最小点为 s₊、s₋，对应值为 F₊、F₋。

1. **后验（Gibbs）反演。** s̄ = π₊s₊ + π₋s₋，其中 π₊ = sigmoid((F₋ − F₊)/τ)。
   - τ→0 时就是原来的硬分支选择。
   - 在温度 τ 下，它是两个分支的后验均值。低置信的样本自动得到接近 0 的活动值，这就是“滤噪”。
2. **温度自退火。** τ_t = c·r̂²_t，其中 r̂²_t = mean_i (y_i − |k_i·w_t|)² 是每个序列当前的残差方差。
   - 初值 w≈0 时 r̂² ≈ E y²，温度很高。此时 s̄ ≈ ρa/(2+ρ) + 4ρy²a/((2+ρ)²τ) 关于 a 是线性的，LS 步变成 w ← (KᵀK+μI)⁻¹KᵀD_{y²}Kw 加一个常数缩放，即谱估计量的幂迭代。
   - 拟合变好后，τ 下降到噪声水平 c·σ̂²；无噪声时 τ→0，回到精确反演。
   - 所以一个温度参数把谱方法（τ=∞）与精确反演（τ=0）连在一起，也补上了 CV 低采样端的初始化缺口。
3. **泄漏乘子。** 对 s − Kw − z = 0 做 ALM，并给松弛 z 加高斯惩罚 ‖z‖²/(2g r̂²)。对 z 求最小后得到 λ⁺ = (λ + ρr)/(1 + ρ g r̂²)。
   - 不动点为 λ = r/(g r̂²)，也就是高斯得分，乘子有界而不会漂移。
   - g→0 时回到标准 ALM。
4. **折叠正态读出。** ŷ_q = a·E|N(m_q, sr·r̂²)| + b，其中 E|N(m,s²)| = s√(2/π)·e^{−m²/2s²} + m·erf(m/(√2 s))。
   - 这是读出层的改动，不属于内更新。所有 |w·k| 记忆（包括 TTT-GD）都同样使用它，保证比较公平。

c、g、sr、LS 岭系数 μ 与校准系数 a、b 都是标量，由外层在训练属性上学习。

**消融 TTT-GD-soft：** 使用同一个噪声校准的局部目标 s̄（λ=0），但用梯度步 w ← w − η·(2/n)·Kᵀ(Kw − s̄) 代替提升 LS 加泄漏乘子。它等价于在温度 τ 平滑后的值函数上做梯度下降，用来区分收益来自“噪声感知的目标”还是“提升的局部求解加乘子”。

**读法：**

1. **NLP 上噪声缺口被修复。** 同样的读出下，原 PC-ALM 与 PC-ALM-σ 的差异完全来自内更新：
   - NLP 4d 从 0.945 降到 0.710，从最差变成最好。
   - Graph 上不成立：精确 LS 版的 PC-ALM-σ 在 4d 为 0.961，比硬反演加同读出的 0.871 还差，8d 两者持平（0.836 对 0.846）。
   - Graph 上的收益来自读出与梯度型参数步，见第 3 点。
2. **TTT 与 PC 局部反演结合，在两个真实领域都优于 TTT 自己的梯度更新、二次闭式头与 Transformer。**
   - NLP 4d：0.710 对 GD 全批量 0.752、官方 0.840、二次岭 0.771、Transformer 0.953。
   - Graph 4d：GD-soft 0.707 对 0.871 / 1.009 / 1.029 / 1.146。
   - 两个胜者的内更新都以 PC 的局部两分支后验活动为目标。区别是 LS 精确求解，还是梯度步。
3. **第二个缺口：Graph 上精确 LS 参数步不如梯度步。**
   - GINE 表示重尾，n=2d 时 LS 几乎插值；
   - 同一个软目标下，梯度步（GD-soft）在 4d/8d 更好，但在 2d 出现重尾失败（均值 2.43、中位数 0.81）。
   - 修复：近端 LS 参数步 w⁺ = argmin ‖s+λ/ρ−Kw‖² + μ‖w‖² + p‖w−w_t‖²，其中 p = prox·tr(KᵀK)/d，prox 由外层学习。p→0 就是 PC-ALM-σ，p 大时是朝同一软目标的隐式梯度步。
   - 同时加入同 ρ 无乘子对照（pcalm_prox_nolam），检验噪声下乘子是否仍有因果作用。
   - 运行中：`r4_*`。

### 4.1b 后续缺口与修复（逐个定位，逐个修复）

每个修复都只加一个在无噪声极限下消失的项。

| 版本 | NLP 2d / 4d / 8d | Graph 2d / 4d / 8d | 缺口 → 修复 |
|---|---|---|---|
| PC-ALM-σ（精确 LS） | 0.789 / 0.710 / 0.677 | 1.392 / 0.961 / 0.836 | Graph 上精确 LS 插值重尾噪声 → 近端 LS 步 |

| + Huber 松弛（截断乘子） | 0.810 / 0.751 / 0.722 | 1.149 / 0.928 / 0.857 | 不是离群点问题：κ 未被触发，CV 上结果与 prox 完全相同 |

| **prox + df 校正噪声估计，g 初值 10（最终）** | 0.809 / **0.711** / **0.674** | **0.867 / 0.742 / 0.688** | — |
| 同上，g 初值 1 | — | 1.162 / 1.030 / 0.965 | g 从低噪声端开始则停在低处 |

**第四个缺口（噪声估计有偏）：**
- r̂² 是上下文残差。带乘子的提升拟合会把噪声吸收进拟合，使 r̂² 被压低，泄漏随之变弱，拟合更紧，形成正反馈。
- n 越小越严重：2d 时 n=32、d=16，失败也最重。
- 修复：用经典无偏估计 r̂² = RSS/(n − df)，其中 df = tr((G+μI)⁻¹G)，直接由 LS 步已有的 Cholesky 因子得到。
- 效果：Graph 从 0.930/0.816/0.764 降到 0.867/0.742/0.688，与无乘子版本持平或更好（4d 0.742 对 0.759）。NLP 保持 0.711/0.674。

**g 的初值：**
- g 表示“活动变量与预测之间耦合的噪声方差”。外层对 g 的梯度很弱，g 基本停在初值附近（与 448 中学 ρ 的漂移同类）。
- 从高噪声端（g=10，接近无乘子）开始是安全的：
  - NLP 上外层把 g 降到 4.9；
  - Graph 上降到 6.3；
  - 无噪声时，r̂² → 0 使泄漏 → 0，仍回到原 PC-ALM。

**最终配置：** 同一个模型、同一组初值用于 NLP 与 Graph，不做逐领域选择。与 449 的全部基线相比：
- NLP 4d：0.711 对 TTT-GD 0.752、二次岭 0.771、Transformer 0.953；
- Graph 4d：0.742 对 0.871、1.029、1.146。

GD-soft（PC 局部反演加梯度步，同属 TTT×PC 组合）在 Graph 4d/8d 仍略好（0.707/0.635），但 2d 均值为 2.43（重尾失败）。

1. **缺口已指出并修复。**
   - 真实任务的噪声在 |·| 里面，这打破了原 PC-ALM 的四个无噪声假设：硬分支、未泄漏乘子、|w·k| 读出、残差噪声估计。另有一个近不可辨识区的点估计缺口。
   - 对应修复分别是：后验反演（自退火）、泄漏乘子（g 从高噪声端开始）、折叠正态读出、df 校正噪声估计、近端 LS 步，以及多链似然加权。
   - 每一项在 σ→0 时都退回原 PC-ALM。
2. **修复后，同一个 TTT×PC-ALM 配置在三个真实领域都优于 TTT 自身的梯度更新（官方与全批量）、二次闭式头（“固定非线性特征＋闭式”）和 Transformer（“加层”）。**
   - 第二种子复现，配对检验几乎都达到 p<1e-6。
   - 唯一例外是 CV 2m 对二次闭式：均值持平，但 PC-ALM 在 70% 的序列上更好。
3. **诚实的边界。**
   - NLP 2d：GD-soft 比 PC-ALM 好 0.013，GD-soft 本身也属于 TTT×PC 组合（PC 局部后验反演加梯度步）。
   - CV 3m–6m：GD-soft 多链的中位数更好，但尾部更重，均值不如 PC-ALM。
   - 距离全标签探针上限（NLP 0.57、Graph 0.44）仍有差距，这部分由少样本本身决定。
   - 合成 σ=1 桥接任务所有方法都学不会（NMSE 约 1），不能作为证据。
   - 第 4 节的修复顺序是看着留出结果逐步做出的；第 5 节换种子、固定配置的复现是对这一点的检验。

## 7. 受控桥接：同一合成任务上噪声从 0 加到 0.5

- 任务：合成属性，属性方向位于隐藏的 16 维子空间；15 个属性用于训练，5 个留出；n=4d 训练。
- 数据来源：`r3_synth_*`、`r11_synth_*`、`r12_synth_s0`。
- 最终配置指 prox + df + g 初值 10；换成噪声缩放的近端权重后，σ=0 结果相同（0.967/0.553/0.393）。

- **缺口的受控复现。** σ=0 时原 PC-ALM 远好于 GD、闭式与 Transformer（4d：0.312 对 ≥1.0），与 448 一致。σ=0.5 时它完全失效（1.005），这正是 449 在真实任务上看到的现象。
- **修复后的版本在 σ=0.5 时胜出。** 4d 为 0.909、8d 为 0.724，对照 GD 为 1.038/0.983，二次闭式为 1.048/1.012。
- **σ=0 时仍然大幅领先基线，但不及原硬版本。** 4d 为 0.553，原硬版本为 0.312。噪声缩放的近端权重没有改善，所以原因不在近端步；更可能是温度 c 与泄漏 g 的外层梯度太弱，停在初值附近。

## 8. 尚未解决的两点

1. **g 初值依赖噪声区间。**
   - NLP/Graph 需要从高噪声端开始（g=10）；按训练损失选择也会选 g=10，与留出结果一致。
   - CV 更接近精确区，g=1 更好：多链 2m 为 0.213，g=10 时为 0.594；3m–6m 两者相同。CV 的训练损失估计太吵，不足以做选择。
   - 所以 CV 2m 的“持平”依赖 g=1 这个选择。统一使用 g=10 时，CV 2m 输给二次闭式，3m–6m 仍然胜出。
   - 修复方向：用训练集中留出的验证图像或属性做 g 选择，或直接由数据的噪声比（df 校正的 r̂² / E y²）设定 g，不再学习 g。
2. **σ=0 时噪声校准版本丢掉了一部分硬反演的优势**（0.553 对 0.312）。修复方向同上：把 c 与 g 设为噪声比的确定性函数，使精确区自动变硬。
