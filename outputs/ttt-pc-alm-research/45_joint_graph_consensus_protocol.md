# 45. 联合共享偏置投影：在运行前写清公式、先例与验证

44轮180行已完成。24参数精确块ALM480全程MSE .00474364，去乘子 .0688897，导数块带乘子 .0592907；先验矩闭式头 .162111。机制部件确有作用，但最好的批量Adam240(.01)为 .00120641且约快8倍。不能宣布独立算法优势。

下一改动由慢的局部协调问题出发，而不是加轮数：将仿射关系和非线性图关系分别作为两个集合，一次精确联合投影活动、预激活和共享偏置，采用两集合共识ADMM。局部投影神经学习有明确先行工作，例如[Learning without loss](https://arxiv.org/abs/1911.00493)、[Three-weight message passing](https://studios.disneyresearch.com/2013/05/08/an-improved-three-weight-message-passing-algorithm/)。**这里不把通用投影或ADMM视为新贡献，也不称这是原始PC-ALM的逐字实现。**

## 1. 两个集合

A包含每层z_l=h_{l−1}W_l^T+b_l和b_l∈[−.3,.3]；h_0=x固定。B包含各元素h_l=g(z_l)，末层另满足已观察噪声带。A、B的交集恰好是44轮同一真实网络的可行写入集合，没有给候选改变目标。

每个A块只使用(h_{l−1},z_l,b_l)，不同层块在A内不共享变量，可以并行。B块只使用(z_l,h_l)，也互相独立。通过共识乘子跨两组传递约束，未执行全网链式反传。

## 2. A的联合闭式投影（是内部局部子问题，不是完整闭式回归）

投影输入为H,Z,b⁰，最小化

\[\tfrac12\|\widehat H-H\|_F^2+\tfrac12\|\widehat Z-Z\|_F^2+\tfrac12\|\widehat b-b^0\|^2,
\quad\widehat Z=\widehat H W^T+\widehat b.\]

W正交时先消去H、Z，得到

\[\widehat b=\Pi_{box}\frac{\sum_i(Z_i-H_iW^T)+2b^0}{n+2},\]
\[\widehat H=\frac{H+(Z-\widehat b)W}{2},\qquad
\widehat Z=\frac{Z+HW^T+\widehat b}{2}.\]

第一层H=x不可动，改为b̂=Π_box[Σ_i(Z_i−x_iW^T)+b⁰]/(n+1)，Ẑ=xW^T+b̂。最后一层h_L不被A限制，它的噪声带属于B。

证明：正交W保欧氏范数，消元后的目标为¼Σ_i||Z_i−H_iW^T−b||²+½||b−b⁰||²，逐坐标完成平方，故有上述投影。此处没有将联合非线性参数适应谎称存在一遍闭式解。

## 3. B的精确图投影与乘子

给定(z⁰,h⁰)，每个分支g(z)=sz+c的候选为

\[\widehat z=\Pi_{I_s}\frac{z^0+s(h^0-c)}{1+s^2},\quad\widehat h=g(\widehat z).\]

末层把分支区间I_s与输出噪声带的逆像相交。比较四个分支的平方距离取最小。与旧更新区别在于**z与h同时投影到真实非线性图**，而不是只在固定另一变量时更新一个坐标。

令c保存B侧状态，u为零初始化scaled dual：a←P_A(c−u)，c←P_B(a+u)，u←u+a−c。b在B没有限制，故其共识乘子恒为0，可消去；参数状态仍保留。去乘子即简单交替投影，作为必要对照。

固定全部分支后，A与B为闭凸集（B的末层为仿射图与区间交集），可在可行条件下调用标准凸两块ADMM的保证；完整问题含分支切换，不据此声称非凸全局收敛。真实查询只能由选出的b前向计算，不能使用自由活动。

## 4. 固定小试验

复用44轮4开发流、3×8网络、8/16/24上下文、512向量查询。共识30/120/480轮；去乘子交替投影480；旧精确块ALM480；批量Adam240(.01)；批量GN20；先验矩1024。所有内部方法256先验任务、16起点、同支持选择准则，无几何精修。8×4×3=96行。数据全为开发，不宣布显著性。

预期：若联合块消元有效，应以更少完整计算达到同等或更小真实写入误差；若只改善集合距离却不改善前向预测，不通过。去乘子对照隔离共识信用，最好的批量BP与强闭式头继续保留。没有进一步ρ/松弛网格。

事前核验：6个独立SLSQP二次投影对照，最大目标差8.88×10⁻¹⁶；18个分支图密集网格；两投影幂等性、末层噪声带约束；禁用全网BP接口运行候选。数学推导与这些核验只保证块实现正确，不提前保证任务收益。
