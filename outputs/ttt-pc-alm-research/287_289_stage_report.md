## 二、这次额外查到了什么机制

我们重新检查全部 64 个旧开发任务、每任务 33 个共同起点，共 2112 起点及四方法的 256 个保存轨迹文件，没有读取新的查询答案，也没有重新适应。

**起点梯度为零不能解释本批差异。** 2112 个起点的浮点实现梯度和精确有理参考梯度都非零；它们也都没有完全进入支持误差带。因此，“BP 已经卡死、只有 ALM 能动”虽然可在特定构造成立，却不是这批共同起点的事实。保存轨迹同时验证：ALM 与无乘子对照首步原变量逐位相同，后续 ALM 的 1114112 个乘子标量递推与 `u←u+r/2` 精确重放一致。

**更具体的正向证据是搜索到不同的有效解释。** ALM 相对共同池新增 191 个任务内正体积分支，BP 新增 214 个。数量上 ALM 没有更多，但不能据此推断这些分支的重要性。

利用既有支持后验完整枚举作为离线参照，对各分支按体积加权后得到：

| 搜索池 | 平均覆盖的数值后验质量 |
|---|---:|
| 共同原子试探池 | 75.06% |
| 试探后无乘子续接 | 78.05% |
| 试探后 Adam240 | 84.40% |
| 试探后 ALM | 86.63% |
| ALM 与 BP 结果的离线并集 | 89.57% |

ALM 独有而 BP 未发现的 72 个任务内分支，平均占完整数值后验的 **5.18%**；反方向 BP 独有质量为 **2.95%**。即使再排除无乘子对照找到的分支，ALM 仍独有 62 个、分布在 30/64 个任务，平均质量 **4.68%**。这不是按查询效果挑出来的子集，而是所有固定任务上的集合差定义。

## 三、为什么这值得继续，但还不是论文结论

在已声明的均匀盒先验、均匀带状噪声条件模型下，后验在支持可行集合 Ω 上均匀。若搜索只发现其中质量为 c 的部分 S，则截断后验与完整后验满足

\[
\mathrm{TV}(\pi_S,\pi)=1-c,\qquad
|\mathbb E_{\pi_S}f-\mathbb E_\pi f|\le1-c\quad(0\le f\le1).
\]

因此，大质量遗漏是一个有数学意义的推理瓶颈；内部局部更新的价值可以来自在有限成本内覆盖这些遗漏，而不只是降低支持集拟合误差。这也说明必须区分分支数、分支质量和最终查询误差。

不过，覆盖率增大只收紧一个最坏情况界，不保证每项实际误差单调改善。三个等质量分支预测分别为 0、1/2、1 时，仅保留中间分支已经给出正确均值；再加入 0 分支虽然提高覆盖率，预测反而偏离。该反例和 TV/平方风险恒等式已经用精确有理算术自检。

本次体积仍为数值积分：64 项枚举先前已通过严格排除和零测边界审计，这次又核对了1658份参考文件及数值单纯形体积，最大相对重构差约1.53×10⁻¹⁴。它不是精确实数后验，也不是候选在线可免费获取的“标准答案”。

## 四、接下来要解决的具体问题

下一目标是：**用支持侧可计算的局部信用和分支结构，在原预算内优先发现能改变预测的重要解释，并让这种改动在新冻结任务上胜过采用相同机会的强 BP。** 不把旧任务上的86.63%当作新任务收益，也不先确定一套看曲线挑出的调度规则。

同时必须补齐288提出的已知值域回归读出。对真值 y∈[0,1]，预测投影到[0,1]逐点不增平方误差；未投影的普通/先验回归应有更强版本。55个精确不等式检查及旧两任务全部54读出/108预测数组标量比对已完成：8项读出变化，候选在这两个旧任务逐位不变。随后，同源码的旧两任务完整预测→评分→独立统计前检也已通过。**全8192任务投影已于美东15:06:25开始，尚无全量补充质量结论**。这仍是已用数据的追加审查，不能据两任务外推恒等或风险改善量；全部新结果另存，不覆盖本轮。

核心目标继续保持：机制、同信息、匹配资源、独立新任务收益缺一不可。当前没有新增官方 TTT、一般 MLP 或 LLM/VLM 验证。
