# 217｜让信用证书只在可能有用的地方计算

## 得到了什么

我们得到了一项**有严格安全条件且已测到组件净收益**的改进：先廉价计算信用证书目标的上界；若整库方向都不可能给出正证书，就跳过昂贵的信用下界求解。原几何仍检查这些区域，因此不改变可行域、预测或任务信息。

在全部96个原冻结候选池中，最终版跳过2437/3998区域的信用计算，原732个排除证书、所选方向和完整证明记录全部保留。ALM原生信用组件同轮13.127→10.937ms，减少16.68%；16任务配对差为−2.189ms，描述性95%区间[−3.732,−0.805]ms。计时包含门控构建、门控求值和剩余信用检查。

## 为什么一个上界能节省下界计算

给定分支模式σ，设Yσ包含共享偏置、活动盒、分支输入盒以及z=h_prev+b的线性关系，但尚不强制每层h=sσz+cσ。固定信用方向a的证书目标为

$$D_\sigma(a)=\min_{y\in Y_\sigma}a^\top r(y).$$

若原网络在该分支存在可行点，则该点r=0，故Dσ(a)≤0。反过来，**Dσ(a)>0可以排除分支**。计算D要逐层求解含共享偏置的一维凸分段线性最小化，并遍历整库方向。

现在将每层共享偏置固定在其可行区间中点，保留活动优化，得到子域Yσ,mid⊆Yσ及

$$D_\sigma(a)\le U_{\sigma,mid}(a):=\min_{y\in Y_{\sigma,mid}}a^\top r(y).$$

注意最小化域缩小，所以这里得到的是**上界**，不是可排除区域的下界。若该上界非正，说明这个方向不可能给出正的D证书；不能据此认定原网络可行。

安全流程如下：

```
已观察支持 → 原局部盒收缩 → 本波剩余区域
                                 │
                       全部信用方向的严格上界
                       ┌─────────┴──────────┐
                    全部 ≤ 0           存在 > 0 / 不确定
                       │                    │
                 跳过信用计算         原完整信用证书检查
                       │               ┌────┴────┐
                       │           正证书      无正证书
                       │             排除          │
                       └────────→ 原几何检查 ←─────┘
```

## 中点上界怎样计算

在第l层、第i个支持上，给定前层活动盒[pᵢˡᵒ,pᵢʰⁱ]及本层输入盒[zᵢˡᵒ,zᵢʰⁱ]。共享偏置区间为

$$b_l^{lo}=\max\{-B,\max_i(z_i^{lo}-p_i^{hi})\},\qquad
b_l^{hi}=\min\{B,\min_i(z_i^{hi}-p_i^{lo})\}.$$

确定该区间非空后，令b̄_l=(b_lˡᵒ+b_lʰⁱ)/2。前层活动受限端点为

$$\underline h_i=\max(p_i^{lo},z_i^{lo}-\bar b_l),\qquad
\overline h_i=\min(p_i^{hi},z_i^{hi}-\bar b_l).$$

活动的系数是qᵢ=a_{l−1,i}−s_{l,i}a_{l,i}（首层a₀=0）。因此方向相关的最优活动项是

$$\min\{q_i\underline h_i,q_i\overline h_i\}
-s_{l,i}a_{l,i}\bar b_l-a_{l,i}c_{l,i}.$$

再加输出活动盒的最小线性项，并对层/支持求和，就得到U_mid。活动端点可以随方向变化，偏置只固定一次。这比最初“所有信用共享低/中/高三个原始见证”的界紧得多；原版在3998区域上一个也没跳过。

## 从正确到有用：没有隐藏失败版本

|实现|整池跳过区域|ALM门控后组件|同轮未门控|解释|
|---|---:|---:|---:|---|
|三个共享见证|0/3998|11.624ms|10.351ms|上界过松，无可用跳过|
|方向相关活动＋完整区间|2437/3998|142.832ms|10.677ms|界已有效，区间计算太贵|
|逐层缓存＋单侧向上运算|2437/3998|18.384ms|11.601ms|复用奏效，但仍未抵消成本|
|有证明的绝对舍入余量|2437/3998|10.937ms|13.127ms|本轮首次组件净收益|

最终版不是裸浮点经验阈值。在明确的float64、归一化信用、当前tent盒及n≤4096范围内，[216推导](216_bounded_roundoff_upper_protocol.md)给每层浮点目标的绝对误差余量

$$E_l=1024(n+1)^2\epsilon,\qquad \epsilon=2^{-52}.$$

层值加该余量后向上扩张，输出和跨层仍向上计算；超出适用域则回退到完整区间实现。当前n=4时每层余量为5.6843×10⁻¹²。这份舍入界的用途是保证不误跳过，不是给任务风险加正则。

## 独立整数核验，不以随机前检代替全部检查

[整数审计结果](../../results/bounded_error_primal_gate/component/integer_audit.json)把输入float64盒和信用全部解释为精确二进制有理数，转换为共同分母的Python整数。中点、系数、端点选择和目标加总均用整数运算，与快速误差余量实现不同。

- 全96库、3998区域、1889166个方向的真实U_mid均被记录上界包住。
- 全2437个跳过区域中的840143个方向满足精确U_mid≤0。
- 864项另用Fraction独立交叉核验，全部一致。
- 原732条正证书不被门控删去，组件比较逐次检查记录一致。

这验证了当前全量实例；一般安全性仍依赖216明列的舍入模型及适用条件，不因大样本测试自动升级为任意激活/任意精度定理。

## 下一步实际收益判据

当前发现针对“信用求解本身过贵”这个明确瓶颈，给出了可执行的数学安全门控。是否足以形成任务级收益，必须看[218完整在线比较](218_online_primal_gate_protocol.md)：所有门控/未门控、裸C5/C20、强Adam/PC/no-dual/direct和六类回归共同从头计时；同时核对预测、所有真实跳过方向和额外状态。

若完整流程有净收益，才可将本组件写为系统机制的一部分。它本身没有证明“必须用PC-ALM”，也没有证明比最优闭式估计更低风险；PC-ALM的独立价值仍须由相同先验、信息及合理资源下的发现/信用收益支持，持续目标保持未完成。
