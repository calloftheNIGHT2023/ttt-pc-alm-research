# 158. 一个有严格查询误差下降的联动修复例子

本页提供可手算、可完整有理数核验的正向机制例子：同一个当前状态、同样两个支持观测，任何一次单标量修复均不可行，而一个局部联动块能恢复真实函数。它验证156/157的结构性扩展，不替代整套任务中的强方法比较。

![严格联动修复例子及简单对照](../../results/tied_local_block/tied_block_witness.png)

## 任务与可观察信息

令g(z)=max(0,1−|2z−1|)，f_b(x)=g(g(x+b_1)+b_2)，偏置盒[-.12,.12]²。

两个支持样本是x=(5/32,9/32)，v=(3/4,3/4)。任务真函数为b*=(0,1/16)，但更新器只获得支持样本，不读取查询答案。当前b=(1/16,1/16)，自由活动h_1=(1,1)、h_2=v，乘子u=0；这是一个明确给定的内部状态，不声称由官方算法自然生成。

两个合法切面分别要求

\[
\Phi_i=3/4-g(h_{1,i}+b_2)\le0,\quad i=1,2.
\]

其方向只取输出残差分量。当前第二层位于死区，g(1+1/16)=0；对应单位置闭分支的不可行下界严格大于.7489，完整Fraction证书已保存。这是容易被C20发现的冲突，不属于本项目“主信用库接收C20之外冲突”的独立覆盖证据。

## 为什么一个标量不够

改一个h_{1,i}，另一样本的切面仍违反。改b_1时，独立活动h_1没有联动，两个切面都不变。改b_2时，盒内最多使g(1+b_2)达到2×.12<3/4，仍不够。输出活动按问题定义固定。

所以这不是某个梯度步长选得差：整个单标量可行集合为空。157实现独立复核了该结论。

## 一个局部联动块能做什么

令b_1=t，h_{1,i}=g(x_i+t)，其他变量保持。切面合起来要求

\[
g(g(5/32+t)+1/16)\ge3/4,\qquad
g(g(9/32+t)+1/16)\ge3/4.
\]

在偏置盒内，第一条要求t≥0，第二条要求t≤0，交集唯一为t=0。实际候选恰好可表示：b=(0,1/16)，h_1=(5/16,9/16)。两条切面精确等于零，最终预测函数等于任务真函数。

对独立q∼Uniform[0,1]，分段精确积分得到：

| 方法/表示类 | 全区间精确查询MSE |
|---|---:|
| 原参数／无法采取动作的单标量修复 | 19/384≈.04947917 |
| 两支持点闭式拟合的仿射头 | 155/1024≈.15136719 |
| 即使知道整个真函数的最优仿射头 | 5695/65536≈.08689880 |
| 同候选池只降能量（含原近端项） | 约8.1961×10⁻⁶ |
| 联动候选＋精确切面 | **0** |
| 简单内部参数反解 | **0** |

这里的查询积分不是网格观察到的下降。全部断点和积分使用有理数；最优仿射下界允许oracle知道整个函数，因此它是这一受限表示类的严格下界，而非故意少训练一个线性头。

同候选只降能量会取t≈.000739875，保留一个正切面残差；其近端目标更低，但查询误差非零。这个例子区分了“当前近端能量小”与“恢复符合观测结构的函数”。

## 这页证明到哪里，以及必须保留的简单方法

它证明了单标量与联动块之间的可行性差别，并给出对固定仿射预测器及同候选能量选择器的严格单步风险优势。没有证明任意核回归、足够宽浅层网络或最强BP都不行。

更重要的是，同先验下直接解参数也能得到t=0：由第一条支持方程在该盒内取唯一合法分支即可。这个简单内部反解必须保留为对照，不能把本例包装成“只有PC-ALM才能解决”。乘子在本例为零，故本例也不是乘子独立收益的证据。

这里的零风险是针对明确指定的真函数，不是说两个支持点能在整个二维参数盒内唯一识别真函数。联动块固定当前b₂=1/16时才确定t=0；若允许两个偏置一起变，b=(1/64,1/32)也拟合这两个支持点，但在q=3/4处预测1，而指定真函数预测7/8。因此本页属于构造性存在例子，不是条件Bayes风险或一般少样本可识别性定理。

真正待验证的仍是[157完整冻结轨迹实验](157_tied_block_admission_protocol.md)：在多层、多个未知偏置、有限计算和实际历史信用下，联动机制是否找到强控制遗漏的有效解释，并转化为可复现的未见查询收益。
