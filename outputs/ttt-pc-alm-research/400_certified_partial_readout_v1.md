# 400｜可验证部分后验读出：从搜索未完成到有界预测

2026-09-25。新数学原语与测试计划；不是限时任务收益，也不是 PC-ALM 独占定理。不修改正在运行的 397 冻结代码、预算或主配置。数值测试等 397 原链终结之后执行，避免污染正式计时。

## 1. 具体瓶颈与正向命题

397 的完整区域方法只有全部几何与读出完成才交付新预测；否则使用共同先验备用。强优化器组合已经逐阶段交付，因此下一步应使候选在仍有未解析区域时也能产生有根据的预测，而不是为了完整性承担全有或全无的风险。

设支持 S 可见、查询输入 q 可见、查询答案不可见。当前四层 tent 模型的参数先验为盒内均匀，观测噪声为独立均匀 [-epsilon,epsilon]，因此后验在兼容集合 F(S) 上均匀。以下精确结论针对这个数学观测模型；浮点采样和实际逐任务误差另行验证。令总质量 Z=vol(F)>0，查询输出 f(theta,q) 属于 [0,1]，后验均值 m=积分_F f / Z。

找到可验证子集 K⊂F，质量 M=vol(K)，积分 S_K∈[S_lo,S_hi]，并证明 Z≤Z_bar。未搜索部分仍计入 Z_bar；不能把发现的模式当作完整后验。则

    L = S_lo / Z_bar
    U = 1 - (M - S_hi) / Z_bar
    L ≤ m ≤ U。

证明：积分_F f≥S_lo，且积分_F(1-f)≥M-S_hi，分别除以 Z≤Z_bar。区间宽度为

    U-L = 1 - M/Z_bar + (S_hi-S_lo)/Z_bar。

它分别刻画未覆盖质量和已覆盖部分的积分误差。只有模式数量更多、质量更多但没有输出信息，都不自动使界足够有用。

## 2. 对任意基线的可证明修正

任意基线 a（包括闭式回归、浅头、TTT、BP）的修正为 a'=clip(a,L,U)。因为 m∈[L,U]，有

    (a'-m)^2 ≤ (a-m)^2。

若 a<L，降低量为 (L-a)(2m-a-L)≥(L-a)^2>0；a>U 对称。若 m 确实等于任务生成分布下的条件目标均值，则平方风险分解进一步给出

    E[(a'-Y)^2 | S,q] ≤ E[(a-Y)^2 | S,q]。

这是一个明确的正向充分条件：证书区间排除了基线预测时，可在不看查询答案的情况下严格降低条件期望风险。它不是每个固定教师、每个查询的实际平方误差都下降，也不保证强基线会落在区间外。先验／似然失配时仍可约束指定后验泛函，但上述真实风险保证不自动成立。

累计证书取区间交集，只要各证书有效就保持包含 m，区间不扩大。空交集必须报错；不通过扩大数值容差掩盖错误。获得证书的全部成本须计入预算，投影本身不是免费优势。

**所有基线均可使用相同证书投影。** PC-ALM 要证明的独立作用是：其局部信用与安全排除在相同预算内更早提供有信息的界，而不是独占投影公式。必须包括 BP/PC/PDHG 搜索 + 同一读出、相同证书传递接口，以及未经投影的原基线。

## 3. 精确下界而非数值体积冒充证明

浮点几何只提供点云／面的候选。将这些浮点坐标解释为精确二进制有理数，以已验证严格内点为中心做共同收缩，直到每个顶点严格满足所有非恒定仿射约束。凸性保证整个点云凸包位于兼容模式内。

对候选面，精确验证所有点云顶点位于同一半空间，且共同顶点均值不在面上。仅保留每个精确支撑超平面的一个面单纯形。以共同顶点均值为锥顶，连接各保留面：不同支撑平面的锥内部只在零测集相交。因而这些单纯形的精确行列式体积之和是可验证下界。非支撑面、重复平面、退化面必须丢弃。这样可能损失大量体积，但绝不以 Qhull 的浮点体积代替严格下界。

跨模式求和还需证明模式内部不重叠且键唯一。当前每层自由偏置使激活边界是非恒定仿射等式，因此不同完整模式仅在零测边界相交。该结论不能无条件推广到活动恒为拐点的一般网络。

## 4. 查询积分与总质量上界

既有 287 系列已经实现并审计过精确单纯形读出区间及仿射包络（`probe_simplex_readout_intervals.py`、v3），以及完整有理几何证书。本轮复用既有四层区间实现，不把单纯形二分、区间传播或精确体积认证本身当作新贡献。新的接口重点是无需完整搜索的内质量／总质量上界和保守基线修正；采用更便宜而可能更松的内锥下界，也不自动优于已有完整几何认证。

若一个单纯形的所有顶点在每层都处于同一个闭合线性段，归纳可知该层及后续已验证层对参数都是仿射的，故输出平均等于顶点输出平均。否则以偏置坐标范围做严格区间传播；有限次最长边二分产生两个等体积、不重叠子单纯形，可以收紧积分界。禁止仅凭顶点输出范围处理跨 tent 峰值的单纯形。

总质量上界必须覆盖已解析与未解析的全部可行域。最保守的先验盒体积始终可用。更紧的单区域上界可选 d 个独立约束方向构成 T，将已有正／负比例行给出的区间写成 l≤T theta≤u；对应平行多面体体积为乘积(u-l)/|det(T)|，只需有理数验证。求解器可提出方向，但不能直接把浮点 LP 最优值视作已证上界。

多个覆盖块的上界可相加，重叠会使上界偏大但不破坏安全。使用部分搜索森林还需独立证明其覆盖了未排除的参数；本原语不会自动作出该保证。当前仅准备原语，尚未接入在线搜索与实际模式归档。

此外必须保留无需搜索的简单证书控制：四层 tent 对输入的全局 Lipschitz 常数为 16，故所有兼容参数的输出都位于各支持区间 `[v_i-epsilon-16|q-x_i|, v_i+epsilon+16|q-x_i|]` 与 `[0,1]` 的交集。它同时包含后验均值；若真实参数确实兼容，还包含该参数的查询输出，给出更强的逐查询平方误差投影保证。不能把这类廉价约束修正能解释的收益归给 PC-ALM。400 当前代码只实现质量／积分原语，这个控制应在真实支持诊断与下一轮限时接口中加入并计费。
