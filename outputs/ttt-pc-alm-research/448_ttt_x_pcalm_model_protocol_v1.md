## 0. 目标更正（用户明确指出）

研究目标从来不是“PC-ALM 单独的独立价值”，而是 **PC-ALM 与 TTT 结合后产生的有效价值**：在推理时用已观察上下文更新内部记忆，PC-ALM 作为 TTT 的更新机制，是否比 TTT 原本的梯度更新、闭式回归/固定特征头、加一层网络更有效。

440–447 中“能否胜过 GAMP/AMP”是我自行加的附加标准。AMP 是另一种可以放进 TTT 的更新规则，作为参照保留，但它不是这个组合是否有效的判据。

按正确标准，理论实验层已经给出的结论：

| 同一内部记忆 f(k;w)=g(w·k)、同一上下文 | TTT 原梯度更新 | 回放 BP（Adam/GD/LM） | 闭式、核与加一层 | **TTT×PC-ALM** |
|---|---|---|---|---|

## 1. 本轮问题

上面的结果都是在固定键上做推理时适应，还没有进入端到端训练的模型。本轮检验：把 PC-ALM 放进一个用外层反向传播训练的 TTT 层之后，这一收益是否还在？外层能否学会键投影？

## 2. 任务（上下文学习，Garg 等 2022 的形式）

- 每个序列：观察 o_i=M[x_i; z_i]∈R^{2d}，其中 x_i~N(0,I_d) 是信号，z_i~N(0,I_d) 是干扰，M 是对所有序列固定、但模型不知道的随机正交混合矩阵。
- 标签 y_i=He₃(u·x_i)/√6+0.1ε，u 按序列随机。
- 上下文 n 对 (o_i,y_i)，另有 64 个查询 o_q，查询标签只用于损失与评估。
- 外层必须学会从 2d 维观察中找出信号子空间；内循环必须在每个序列内找出 u。
- 训练时 d=32、n=4d，数据无限（每步新鲜抽样）；评估时 n∈{2d,3d,4d,6d}，各 2048 个新序列。

## 3. 模型（外层可训练部分相同：键投影 θ_K∈R^{d×2d}）

内部记忆一律为 f(k;w)=He₃(w·k)/√6，内循环都从同一个小随机初值出发。

- **TTT-GD（官方式）：** 按块单遍，块=16，每块一步梯度，学习率可学。
- **TTT-GD×K：** 在整个上下文上做 K 步全批量梯度，学习率可学。这是比官方规则更强的梯度内循环。
- **TTT-闭式（MesaNet/岭）：** 内部记忆为线性，w=(KᵀK+μI)⁻¹Kᵀy，查询输出 k_q·w。
- **TTT×PC-ALM：** K 次提升迭代：逐样本一维反演（网格＋牛顿，可微），乘子更新，局部最小二乘参数步；ρ 可学。
- **Transformer：** 4 层，d_model=128，4 头，输入为 [o_i,y_i] 与 [o_q,0]，查询只看上下文。与 TTT 模型使用相同的训练步数和数据量。
- **神谕投影上界：** θ_K 固定为真实信号投影，只跑 TTT×PC-ALM 内循环。

外层都用 Adam，梯度穿过展开的内循环（PC-ALM 中网格 argmin 不可微，牛顿步与最小二乘步可微），训练步数相同。

## 4. 预测

1. TTT-GD（两种）、TTT-闭式在 n=4d 时的查询 NMSE 接近 1，外层无论怎么学都无法弥补内循环的 CSQ 瓶颈和线性表达能力的限制。
2. TTT×PC-ALM 的外层能学会信号子空间（与真实投影的子空间重叠接近 1），在 n≈4d 时接近神谕投影上界。
3. Transformer 在同等训练预算下难以学会 He₃ 单指标的上下文学习，结果如实报告。

如果 TTT×PC-ALM 的外层训练学不动（梯度穿过离散分支太弱），就如实报告，并尝试事先声明的替代方案：只对最终最小二乘步求导的一阶近似。

# 结果（2026-09-26，运行后补写）

## 执行中的调整（保留记录；第 1 项在正式运行前，第 2 项在看到正式结果后）

1. **神谕内循环扫描**（sweep_oracle_*）：在真实投影下，ρ=0.1 的 float32 内循环几乎不工作（n=4d 仅 6–8%），ρ=1 时为 97%。锚点去相关在这里没有带来差别。因此正式运行把 ρ 的初值设为 1，关闭去相关，内迭代 K=30。
2. **ρ 由外层学习的版本失败**（m1_ttt_model_d32 中的 ttt_pcalm）：外层梯度把 ρ 从 1 推到了 219。ρ 这么大时，局部反演被拉在锚点附近、无法跳分支，成功率为 0，尽管此时子空间重叠已到 0.96。原因是网格 argmin 不可微，外层梯度看不到分支跳跃的收益，便倾向于把求解器调得“更平滑”。这与主线中“梯度信用看不到分支变化”的机制一致。v2 把 ρ 当作固定的求解器超参数（ρ=1），这是**偏离预注册协议**的修改；原失败结果保留。

## 主结果（d=32，训练 n=4d，每个模型训练 2000 步 × 64 个序列；评估用 2048 个新序列）

| 模型 | 学到的键投影与信号子空间重叠 | n=2d | n=3d | n=4d | n=6d | n=4d 中位 NMSE |
|---|---:|---:|---:|---:|---:|---:|
| **TTT×PC-ALM（ρ 固定为 1）** | **0.999** | 0.18 | **0.77** | **0.90** | **0.96** | **0.020** |
| 参照：真实投影＋PC-ALM 内循环（不训练） | 1.0 | 0.23 | 0.86 | 0.96 | 0.99 | 0.013 |
| TTT 官方梯度（每块 16 个，一步） | 0.51 | 0 | 0 | 0 | 0 | 0.995 |
| TTT 全批量梯度 30 步 | 0.49 | 0 | 0 | 0 | 0 | 0.996 |
| TTT 闭式线性（岭 / MesaNet） | 0.42 | 0 | 0 | 0 | 0 | 0.994 |
| Transformer（4 层，d_model=128） | — | 0 | 0 | 0 | 0 | 0.996 |
| TTT×PC-ALM（ρ 可学，漂到 219） | 0.96 | 0 | 0 | 0 | 0 | 1.048 |

表中除重叠与 NMSE 外均为成功率（NMSE<0.05）。

**结论（第三层的第一个模型实验）：**

1. 把 PC-ALM 放进端到端训练的 TTT 层后，外层反向传播穿过内循环，学会了从 64 维观察中找出 32 维信号子空间（重叠 0.999）。任务表现接近直接给出真实投影的参照（n=4d 时 90% 对 96%）。
2. 同样的外层、同样的数据与训练步数下：
   - TTT 原有的梯度内循环（官方单遍与全批量）、闭式线性内循环、4 层 Transformer 的查询误差都停在约 1，完全失败；
   - 这些模型的外层连信号子空间都学不到（重叠 0.42–0.51，接近随机）。
   也就是说，TTT 与 PC-ALM 结合带来的价值不只在内循环本身，还在于它让外层学习得到了可用的信号。
3. ρ 必须作为求解器超参数固定；交给外层梯度学习会让它失效。

**限制：**

- 单一随机种子，只做了 d=32；
- Transformer 只训练了与 TTT 模型相同的 2000 步，上下文学习文献中通常要多得多；
- 任务是合成标签的上下文学习，还不是真实下游任务。
