# 390｜当前任务分布的官方 TTT 强对照：实现草案

2026-09-25。冻结前状态：六配置数值预检已通过；正式八模型训练即将按本协议启动，尚无其训练结果或查询比较。与 389 的真实模型阶段不同，这里是补齐当前受控理论任务的强基线。启动时训练程序保存本文件及源码哈希，此后不修改此版。

## 为什么不能沿用旧桥接权重

官方源码的 fast-weight 更新可以复用，但旧 official_ttt_meta_bridge.py 的教师是阈值位于 [.4,.6] 的非对称 tent 复合，支持输入分层采样且没有当前观察噪声。387 教师则是四层 max(0, 1-|2(h+b)-1|)，b∈[-.12,.12]，24 个 iid 支持，均匀 ±.001 观察噪声。旧权重不是这一任务的匹配训练基线。

## 新增与不变内容

matched_official_ttt_v1.py 继承原桥接表示和读取，所有内部快权重更新直接调用固定官方提交 cd831db10c8c9a0f6340f02da5613316a8a92b67 的 TTTMLP.ttt；不改第三方源码。输入 key 来自 x，value 为 key + value_code(v)，官方重建目标仍为 V-K。候选主方法不调用此全局链式更新，只有明确标记的 TTT 控制使用。

新增支持 4 / 8 / 16 / 24 前缀与显式快状态传递：warm 模式按完整前缀重复暴露 52 条支持，和现有 meta-shallow 的训练轨迹一致；另保留 cold24 入口但不能把 warm 训练模型的 cold24 表现单独当作最强基线。每次内部 pass 的支持复用次数及 fast gradient carry 都计账。

进一步源码核对发现旧桥接固定 token_eta=1，并不等于官方 get_eta 的 token 累计缩放和输入依赖学习率门控。预检与正式训练尚未运行时，设计补齐 native 模式：直接调用官方 get_eta，开放 learnable_token_idx、learnable_ttt_lr_weight / bias 的外层训练，关闭不再使用的桥接标量率。保留 legacy 标量版本作为消融，不将它冒称原生步长规则。原模型仍是任务桥接器，不是完整预训练语言模型。

新驱动在 float64 下显式对齐 rate / token 张量的 dtype；旧驱动部分张量使用默认 float32，所以只对旧 float32 cold24 声称可检验的逐位复现。float64 用独立 autograd 参考验证：对当前快权重计算半平方重建损失的全支持梯度，每个 pass 一次同时更新；不是每个 token 重新计算梯度的顺序 SGD。

## 独立预检与冻结前门槛

test_matched_official_ttt_v1.py 仅用旧任务，检查六配置 × 四前缀 cold / warm、独立梯度参考、教师一致、先验特征逐项前向、A→B→A 重置、query 置换只读、批式与逐任务一致、观察值确实影响快状态、推理时慢权重不变、完整二阶外层梯度可用及原 float32 桥接复现。native 梯度参考不调用 get_eta，而用线性门控与最终 token 缩放独立重建逐 token 权重，再对加权重建损失求导。每配置还做一个外层 Adam 冒烟步及内存 checkpoint 保存／重载一致性测试；这些单步检查不是正式元训练或任务效果证据。

脚本在导入 Torch 前要求 387 预测、审计、评估全部通过，避免与正式计时争用 CPU。该链现已结束且全通过，390 预检也已通过：六配置、四前缀、独立梯度与隔离、六次 Adam 冒烟及 checkpoint 往返均成功；教师误差与原 float32 cold24 快状态复现误差均为零。证据为 results/matched_official_ttt/preflight_v1/summary.json；该预检不是正式元训练或任务效果。

## 候选训练与公平性

拟定六个 TTT 配置：四个原生步长先验特征版本 head_dim 16 / 32 × inner_passes 1 / 4，原生步长 scalar 特征 head32/pass1，以及 legacy 步长 prior256/head32/pass1。预列主 official_ttt_native_prior256_32_p1。先验特征版的 key 输入含 x 和与元岭回归完全相同的 seed731/256 教师先验特征，新增表示层可外层训练，在线特征生成完整计费；不改官方快权重更新。保留 scalar 和 legacy 版本以分离新增先验表征、步长驱动与官方更新本身的贡献。

每配置 2000 外层步、batch16、每任务64查询、学习率 .001、Adam 与梯度范数上限1；复用 matched_shifted_meta_models 的分布与四前缀平均平方损失。每配置 32000 外层任务、2048000 唯一生成查询值，四前缀使每个标签四次进入损失，需另报暴露数；所有配置与调参的总成本也单列。

训练使用原配置的训练种子、旧验证任务与选择频率，不读 387 的新测试答案。准确重放旧训练样本还依赖生成设备、dtype 和 Torch 版本；仅同种子不能证明 CPU / CUDA 数据相同。

train_matched_official_ttt_v1.py 因此明确建立一个 CPU/float64 生成并存档的新 cohort，六个 TTT 以及重训的 meta-ridge128 / meta-shallow64_20 共八模型逐 batch 使用完全相同的张量，保存并逐次复核 batch SHA。不声称此 cohort 与历史 CUDA cohort 相同。八模型每个均 32000 任务；每个模型相同数据预算不等于整个配置搜索只花 32000 任务，实际重复暴露和总费用完整报告。原历史权重保留不覆盖。

训练程序只选择旧验证集最优 checkpoint，绝不生成新测试风险；所有随机训练数据、训练与验证标签使用在外层明确收费。warm 前缀、MSE、Adam、验证选择频率与原强元学习对照一致。两个重训对照的增加用来保证逐样本匹配，而不是在本轮风险已知后撤换强控制。
